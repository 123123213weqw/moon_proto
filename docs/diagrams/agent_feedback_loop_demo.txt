Agent feedback loop demo diagram

This is a deliberately labeled demo diagram, not a terminal screenshot.  It summarizes the AI collaboration flow implemented by the repository:

1. Agent or developer proposes a .proto schema.
2. Moon Proto Lab runs Schema Doctor, compatibility checks, codegen, generated-code compile checks, and report generation.
3. Diagnostics such as duplicate field number, invalid map key type, reserved reuse and invalid enum zero value are returned as actionable feedback.
4. The agent/developer fixes the schema and reruns verify/compat/release gate until PASS.
